Game logos for the "Select your game" cards.

Drop the official logo files here with these exact names:

  lol.png         League of Legends logo
  valorant.png    Valorant logo

Notes:
- Any web-servable format works if you also update the paths in wizard.jsx
  (GAMES[].logo) — .png / .svg / .webp are fine. PNG/SVG with transparency
  looks best on the dark card.
- Recommended: a square-ish transparent logo, ~256x256 or an SVG.
- These are Riot Games trademarks — use logos you are licensed to use
  (Riot publishes brand/press assets). If a file is missing, the card
  automatically falls back to the styled "LoL" / "VAL" tile, so nothing breaks.
